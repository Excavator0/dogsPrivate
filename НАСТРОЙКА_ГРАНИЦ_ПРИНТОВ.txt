ИНСТРУКЦИЯ ПО НАСТРОЙКЕ ГРАНИЦ ДЛЯ ПРИНТОВ НА ОДЕЖДЕ
========================================================

Файл: print_bounds.py

ФОРМАТ ЧЕТЫРЕХУГОЛЬНИКА:
Каждая область задается списком из 4 точек в порядке по часовой стрелке:
[(x1, y1), (x2, y2), (x3, y2), (x4, y4)]

где:
- (x1, y1) - верхний левый угол
- (x2, y2) - верхний правый угол  
- (x3, y3) - нижний правый угол
- (x4, y4) - нижний левый угол

ПРИМЕРЫ:

1. Прямоугольник (например, для штанов):
   [(280, 380), (1220, 380), (1220, 1580), (280, 1580)]
   
2. Трапеция (например, для спины худи - уже внизу, шире вверху):
   [(330, 420), (1170, 420), (1100, 1400), (400, 1400)]
   
3. Параллелограмм (например, для рукава):
   [(80, 280), (420, 320), (380, 980), (120, 940)]

КАК ОПРЕДЕЛИТЬ КООРДИНАТЫ:

1. Откройте шаблон одежды в графическом редакторе (например, GIMP, Photoshop)
2. Включите отображение координат курсора
3. Наведите курсор на углы нужной области и запишите координаты
4. Обновите значения в словаре PRINT_BOUNDS в файле print_bounds.py

ВАЖНО:
- Координаты указываются в пикселях
- Точки должны идти строго по часовой стрелке
- Принт будет обрезаться по границам этого четырехугольника
- Стикеры НЕ ограничиваются этими границами (только основной принт)

ПРИМЕР НАСТРОЙКИ ДЛЯ HOODIE_BACK:

Чтобы настроить область спины для худи:

1. Откройте templates/одежда_png/hoodie_back.png
2. Найдите 4 угловые точки области спины:
   - Верхний левый угол (где начинается плечо слева)
   - Верхний правый угол (где начинается плечо справа)
   - Нижний правый угол (низ спины справа)
   - Нижний левый угол (низ спины слева)
3. Запишите координаты каждой точки
4. Обновите в print_bounds.py:

   "hoodie_back": [(x1, y1), (x2, y2), (x3, y3), (x4, y4)]
